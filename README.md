# cyber-sierra-vscode-extension-builder

## Quick install (recommended)

```bash
curl -fsSL https://raw.githubusercontent.com/mathew-v-keyvalue/cyber-sierra-vscode-extension-builder/main/bootstrap.sh | bash
```

Installs a standalone `morpheus` CLI (no system Node.js required) plus the
Cyber Sierra compliance-automation skill, for Linux and macOS. See
[SETUP.md](./SETUP.md) for versioning, rollback, uninstall, and alternative
install methods (VS Code/Cursor extension, manual local install).
